### 검토·시험 규칙(모든 단계 공통)

- 만든 세션은 자기 변경을 검토·시험하지 않는다. 각 단계의 "시험" 항목, 결과 비교, PR diff 대조는 만든 세션이 아닌 다른 세션(지금은 검토·시험 담당)이 한다.
- 시험 결과는 실행한 명령과 실제 통과·실패 수, 테스트 체크리스트 시험 ID로 적는다. 실행하지 않은 검사나 실기기 확인을 통과로 적지 않는다.
- 검토 지적은 만든 세션이 고치고, 같은 검토 세션이 다시 확인한 뒤에만 `[x]`로 바꾼다.
- 모든 PR은 테스트 체크리스트 TR-11(회귀 묶음)을 통과해야 한다.
